Your key is stored only in this browser. On the production site it is sent to the server for the current generation request and is not saved there.

Don't have a Gemini API key yet?
1. Open Google AI Studio → API Keys and sign in with your Google account.
2. Google may create a project and key automatically. Otherwise, choose Create API key and follow the prompts.
3. Copy the new key, come back to Shiur Notes, paste it below, and tap Save key.
Need more help? See Google's official API key guide.
