How to get a Gemini API key
  1. Open Google AI Studio's API Keys page and sign in with your Google account.
  2. If Google already shows you an API key, copy it. If not, click Create API key. Google will either use/create a project for you or ask you which project to use.
  3. Copy the key Google gives you. It will usually begin with AIza.
  4. Return to Shiur Notes, paste the key into the box below, and press Save key.

Google's official step-by-step API key documentation ↗

Your key is stored only in this browser. It is sent to the Shiur Notes server only when you generate something and is not saved on the server.
